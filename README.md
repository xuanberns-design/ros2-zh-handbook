# ROS 2 中文实战速查手册

> 面向中文零基础初学者的 ROS 2 手册。每一节只讲一个**最小可跑通**的例子：完整命令可以直接复制，每一步都有中文讲解，最后附上常见报错的排查方法。

我是一名机器人工程专业的大二学生，刚开始学 ROS 2。这本手册就是我的学习记录：**每一节都在我自己的电脑上实际跑通后才发布**，踩过的坑也都写进了"常见报错"里。

如果它帮到了你，欢迎点个 ⭐ Star，这是我坚持更新下去的最大动力。

## 适合谁看

- 刚接触 ROS 2，看英文官方文档有点吃力的同学
- 想要「复制命令就能跑」的速查资料，不想先啃一堆概念的同学
- 在国内网络环境下安装 ROS 2 时遇到困难的同学（手册里写了换镜像源、GitHub 连不上等问题的处理方法）

## 运行环境

| 项目 | 版本 |
| --- | --- |
| 系统 | Ubuntu 24.04 LTS（我用的是 VMware 虚拟机，带图形桌面） |
| ROS 2 | Jazzy Jalisco |

> 如果你用的是 Ubuntu 22.04 + ROS 2 Humble，大部分命令只要把 `jazzy` 换成 `humble` 就能用，但我没有逐条验证过，请以[官方文档](https://docs.ros.org/en/humble/)为准。

## 每一节都长这样

每一节都用同样的结构，方便你快速找到需要的部分：

1. **本节目标**：这一节要做成什么，跑出什么结果算成功
2. **完整代码 / 运行命令**：可以直接复制
3. **预期输出**：正确运行时你应该看到什么
4. **逐段讲解**：每段命令和代码在干什么
5. **常见报错与排查**：我自己踩过的坑和解决办法
6. **一句话速查**：以后忘了的时候，看这一行就够
